# 👨‍💻 Olubiyi Oluwatise | Full-Stack Engineer Portfolio

A modern, high-performance developer portfolio built with **Next.js 16**, **React**, **Tailwind CSS**, **shadcn/ui**, and **Framer Motion**. Designed with a sleek dark aesthetic, lightning-fast route transitions, and full mobile responsiveness.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** React Icons & Lucide React

---

## ✨ Key Features

- **Lightning-Fast Transitions:** Optimized custom page transitions and component rendering without artificial delays.
- **Fully Responsive Design:** Seamlessly adapted layouts for mobile viewports, tablets, and desktop displays.
- **Interactive Experience & Resume Tabs:** Dynamic tabbed layout showcasing professional experience, education, skills, and about me details.
- **Custom Mobile Drawer Navigation:** Built using shadcn `Sheet` with auto-closing route navigation and a mobile-optimized call to action.

---

## 🛠️ Getting Started Locally

Clone the repository and run the development server:

````bash
# Clone the repository
git clone [https://github.com/Kalabudev/tise-portfolio.git](https://github.com/Kalabudev/tise-portfolio.git)

# Navigate into the directory
cd tise-portfolio

# Install dependencies
npm install
# or yarn install
# or pnpm install

# Run the development server
npm run dev
```This project is open-source and available under the MIT License.
````
